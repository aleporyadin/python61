## Система обліку навчального центру

Створіть консольну програму для обліку студентів, курсів та оцінок навчального центру

## Класи

Створіть класи:

**Student** - студент. Має містити ID, ПІБ, вік, email, список курсів та оцінки

**Course** - курс. Має містити ID, назву курсу, викладача та список студентів

**EducationCenter** - навчальний центр. Зберігає всіх студентів і всі курси

**App** - клас для запуску програми та роботи з меню

## Меню програми

Програма повинна мати меню:

1. Додати студента
2. Показати всіх студентів
3. Знайти студента за іменем
4. Видалити студента
5. Додати курс
6. Показати всі курси
7. Записати студента на курс
8. Поставити оцінку студенту
9. Показати повну інформацію про студента
10. Сортувати студентів
11. Показати статистику
12. Зберегти дані у JSON
13. Завантажити дані з JSON
0. Вийти

## Програма має вміти

- додавати студентів
- додавати курси
- записувати студентів на курси
- додавати оцінки студентам
- шукати студентів
- видаляти студентів
- сортувати студентів
- показувати статистику
- зберігати дані у JSON
- завантажувати дані з JSON

### 14. Редагувати студента

Користувач має ввести ID студента

Після цього програма має дозволити змінити:

- ПІБ студента
- вік студента
- email студента

Якщо студента з таким ID не існує, потрібно вивести відповідне повідомлення

### 15. Редагувати курс

Користувач має ввести ID курсу

Після цього програма має дозволити змінити:

- назву курсу;
- ім'я викладача.

Якщо курсу з таким ID не існує, потрібно вивести відповідне повідомлення

### 16. Видалити курс

Користувач має ввести ID курсу

Після видалення курсу він має зникнути:

- зі списку всіх курсів
- зі списку курсів у кожного студента
- з оцінок студентів

Якщо студент мав оцінки з цього курсу, ці оцінки також потрібно видалити

### 17. Відрахувати студента з курсу

Користувач має ввести ID студента та ID курсу

Після цього потрібно:

- видалити курс зі списку курсів студента
- видалити студента зі списку студентів курсу
- видалити оцінки студента за цей курс

Якщо студент або курс не знайдені, потрібно вивести відповідне повідомлення

### 18. Фільтрувати студентів

Додайте окреме підменю для фільтрації студентів

Фільтрація має дозволяти показати:

1. Студентів конкретного курсу
2. Студентів із середнім балом вище заданого
3. Студентів без оцінок
4. Студентів без курсів

Для фільтрації за курсом користувач має ввести ID курсу

Для фільтрації за середнім балом користувач має ввести мінімальний середній бал

### 19. Створити звіт у файл

Додайте можливість створити текстовий звіт у файл:

`report.txt`

Звіт має бути звичайним текстовим файлом, який зручно прочитати людині

## Що має бути у звіті

У файлі `report.txt` потрібно вивести такі дані:

### 1. Загальна інформація

- кількість студентів
- кількість курсів
- середній бал навчального центру
- найкращий студент за середнім балом

Приклад:

```text
ЗАГАЛЬНА ІНФОРМАЦІЯ

Кількість студентів: 5
Кількість курсів: 3
Середній бал навчального центру: 9.40
Найкращий студент: ST-A3F91C2D, Василь Петренко, середній бал: 11.50
```

Якщо оцінок ще немає, замість найкращого студента можна написати:

```text
Найкращий студент: немає оцінок
```

### 2. Список студентів

Для кожного студента потрібно вивести:

- ID
- ПІБ
- вік
- email
- кількість курсів
- середній бал

Приклад:

```text
СПИСОК СТУДЕНТІВ

ID: ST-A3F91C2D
ПІБ: Іван Петренко
Вік: 18
Email: ivan@gmail.com
Кількість курсів: 2
Середній бал: 10.50
```

### 3. Список курсів

Для кожного курсу потрібно вивести:

- ID курсу
- назву курсу
- викладача
- кількість студентів на курсі

Приклад:

```text
СПИСОК КУРСІВ

ID курсу: 1
Назва курсу: Python OOP
Викладач: Андрій Шевченко
Кількість студентів: 4
```

### 4. Студенти без курсів

Потрібно вивести студентів, які ще не записані на жоден курс
Для кожного студента достатньо вивести:

- ID
- ПІБ
- email

Якщо таких студентів немає, потрібно написати:

```text
Студентів без курсів немає
```

### 5. Студенти без оцінок

Потрібно вивести студентів, у яких ще немає жодної оцінки

Для кожного студента достатньо вивести:

- ID
- ПІБ
- email

Якщо таких студентів немає, потрібно написати:

```text
Студентів без оцінок немає
```

### 6. Інформація по курсах

Для кожного курсу потрібно показати студентів, які на нього записані

Приклад:

```text
КУРС: Python OOP
Викладач: Тарас Шевченко

Студенти:
1. ST-A3F91C2D, Іван Петренко, середній бал за курс: 10.50
2. ST-B7D91F20, Олена Коваль, середній бал за курс: 9.00
```

Якщо на курс ще нікого не записано, потрібно написати:

```text
На курс поки не записано студентів
```
